# One Line, One Laugh — Sock Escape

One line, one laugh: the dryer ate one sock again, and the other one is already halfway to Mexico with the passports. A tiny domestic mystery with an international escape plan — the second beat lands outside the premise, and the closing image is concrete enough to see.

Run `python3 main.py` and it writes the line to `/output/entry.txt` (override with `OUTPUT_PATH` for local testing).
